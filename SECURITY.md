# Security Policy

Please do not report suspected vulnerabilities in a public issue. Until a dedicated security contact is configured, open a private repository security advisory if available, or contact the maintainer through the repository owner account. Include reproduction steps, impact, affected version/commit, and whether sensitive data may be exposed.

The product threat model is in [docs/SECURITY.md](docs/SECURITY.md). The core
v0.1.0 release is public, but this is still an early developer product rather
than a mature security service. Report vulnerabilities privately as described
below; do not include credentials or sensitive fixture data in an issue.
